# Конвертер единиц

Веб-приложение на Flask для конвертации единиц и валют.

## Что умеет

- Длина: км ↔ мили, м ↔ футы, см ↔ дюймы
- Вес: кг ↔ фунты, г ↔ унции
- Температура: °C ↔ °F
- Площадь: м² ↔ фут²
- Объём: литры ↔ галлоны
- Скорость: км/ч ↔ mph
- Валюты: USD, EUR, RUB (курсы загружаются при старте)

История последних 10 конвертаций сохраняется между перезапусками.

## Установка и запуск

```bash
pip install -r requirements.txt
python app.py
```

Откройте в браузере: http://127.0.0.1:5000

## Структура проекта

```
app.py            — Flask-приложение
converters.py     — функции конвертации
rates.py          — загрузка курсов валют
main.py           — CLI-версия конвертера
templates/        — HTML-шаблоны
test_converters.py — тесты
```

## Технологии

Python 3, Flask, Requests
